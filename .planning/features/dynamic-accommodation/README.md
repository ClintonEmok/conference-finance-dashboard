# Dynamic Accommodation Planning

This folder contains the design work for a flexible, event-owned accommodation
system that preserves the existing hotel and physical-room workflow while
supporting reusable event setup through explicit copy/template actions.

The design must cover:

- Event accommodation entities, database structure, and relationships.
- Admin UX for hotels, rooms, ticket accommodation rules, and options/upgrades.
- End-to-end flows from event setup through ticket selection, signup, pricing,
  confirmation, payment tracking, and allocation.
- Dynamic configuration without hardcoded option codes or fixed UI cards.
- Safe reuse, deletion/archive behavior, migration, and historical snapshots.
