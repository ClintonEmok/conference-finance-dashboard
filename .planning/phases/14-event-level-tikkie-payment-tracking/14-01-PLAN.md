# Plan 14-01: Schema + Convex functions for event-level Tikkie links and payment tracking

**Phase:** 14 — Event-Level Tikkie + Payment Tracking
**Depends on:** Nothing (first plan)
**Status:** Not started

## Context

The current Tikkie integration creates one payment link per order. The operator needs a single "open" Tikkie link per event that multiple people can pay into. Individual payments fetched from the Tikkie API need to be stored and matched to orders by payer name.

This plan covers the schema changes and Convex backend functions. The domain logic and API routes are in 13-02.

## Schema Changes

### 1. Widen `tikkiePaymentLinks` (`convex/schema.ts:221`)

Make `orderId` optional and add event-level fields:

```typescript
tikkiePaymentLinks: defineTable(
  v.object({
    providerOrderId: v.string(),
    providerEventId: v.string(),
    orderId: v.optional(v.string()), // was required — now optional for event links
    eventId: v.optional(v.string()), // NEW — event this link belongs to
    linkType: v.optional(
      // NEW — discriminator
      v.union(v.literal("event"), v.literal("order"))
    ),
    paymentRequestToken: v.string(),
    paymentRequestUrl: v.string(),
    status: v.optional(
      v.union(v.literal("created"), v.literal("paid"), v.literal("expired"))
    ),
    statusSource: v.optional(
      v.union(v.literal("create"), v.literal("webhook"), v.literal("poll"))
    ),
    providerStatus: v.string(),
    amountMinor: v.number(),
    description: v.string(),
    expiryDate: v.number(),
    referenceId: v.optional(v.string()),
    providerPayload: v.optional(v.any()),
    providerLastCheckedAt: v.optional(v.number()),
    statusUpdatedAt: v.optional(v.number()),
  })
)
  .index("paymentRequestToken", ["paymentRequestToken"])
  .index("providerOrderEvent", ["providerOrderId", "providerEventId"])
  .index("status_updated", ["status", "statusUpdatedAt"])
  .index("orderId", ["orderId"])
  .index("eventId", ["eventId"]) // NEW index
```

### 2. New table `tikkiePayments` (`convex/schema.ts`)

Individual payments fetched from `GET /paymentrequests/{token}/payments`:

```typescript
tikkiePayments: defineTable(
  v.object({
    paymentLinkId: v.string(),
    paymentRequestToken: v.string(),
    paymentToken: v.string(), // Tikkie's unique payment ID
    payerName: v.string(),
    payerAccountNumber: v.optional(v.string()),
    amountMinor: v.number(),
    paidAt: v.number(),
    description: v.optional(v.string()),
    orderId: v.optional(v.string()), // matched order
    matchStatus: v.union(
      v.literal("unmatched"),
      v.literal("auto_matched"),
      v.literal("manual")
    ),
    matchedAt: v.optional(v.number()),
    providerPayload: v.optional(v.any()),
  })
)
  .index("paymentLinkId", ["paymentLinkId"])
  .index("paymentRequestToken", ["paymentRequestToken"])
  .index("matchStatus", ["matchStatus"])
  .index("paymentToken", ["paymentToken"])
  .index("orderId", ["orderId"])
```

## Convex Functions

### 3. Extend `convex/tikkie.ts`

New queries:

- **`getEventPaymentLink`** — args: `{ eventId: string }`. Query `tikkiePaymentLinks` with index `eventId`, filter to `linkType === "event"`, return first match or null.
- **`getTikkiePaymentsByLink`** — args: `{ paymentLinkId: string }`. Query `tikkiePayments` with index `paymentLinkId`.
- **`getTikkiePaymentsByStatus`** — args: `{ matchStatus: "unmatched" | "auto_matched" | "manual" }`. Query `tikkiePayments` with index `matchStatus`.
- **`getTikkiePaymentByToken`** — args: `{ paymentToken: string }`. Query `tikkiePayments` with index `paymentToken`, return first.

New mutations:

- **`createEventPaymentLink`** — args: `{ eventId, providerEventId, paymentRequestToken, paymentRequestUrl, providerStatus, amountMinor, description, expiryDate, referenceId? }`. Insert into `tikkiePaymentLinks` with `linkType: "event"`, `orderId: undefined`.
- **`upsertTikkiePayment`** — args: `{ paymentLinkId, paymentRequestToken, paymentToken, payerName, payerAccountNumber?, amountMinor, paidAt, description?, providerPayload? }`. Check if `paymentToken` exists; if so skip (idempotent). If not, insert with `matchStatus: "unmatched"`.
- **`matchTikkiePayment`** — args: `{ paymentId: Id<"tikkiePayments">, orderId: string }`. Patch payment with `orderId`, `matchStatus: "manual"`, `matchedAt: Date.now()`.
- **`autoMatchTikkiePayments`** — args: `{ eventId: string }`. For all unmatched payments on event-level links, find orders where `buyerName.toLowerCase() === payerName.toLowerCase()`. If exactly one match, patch payment with `orderId`, `matchStatus: "auto_matched"`. Return `{ matchedCount, totalUnmatched }`.
