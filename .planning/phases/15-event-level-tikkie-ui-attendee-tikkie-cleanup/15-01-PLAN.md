# Plan 15-01: Financial page event Tikkie section

## Objective

Add an event-level Tikkie payment tracking section to the financial page (`/dashboard/financial`). This section shows a collapsible card with an event picker, payment link status, payment list with manual assignment, summary stats, and a button to create an event Tikkie link.

**Purpose:** Centralize Tikkie payment management at the event level on the financial workspace page, replacing scattered per-order Tikkie creation (being removed in 15-02).

**Output:** New `EventTikkieSection` component + modified financial page that renders it.

  <action>
    Create a new `"use client"` component at `components/dashboard/event-tikkie-section.tsx`.

    **Props:** `{ events: Array<{ providerEventId: string; name: string | null }> }`

    **State:**
    - `selectedEventId` — from event picker (default to first event)
    - `eventData` — `{ link, payments, stats }` from GET `/api/dashboard/tikkie-event-links?eventId=...`
    - `isLoading`, `errorMessage`
    - `isCollapsed` — toggle for collapsible section

    **Data loading:**
    - `useEffect` watching `selectedEventId` → fetch `GET /api/dashboard/tikkie-event-links?eventId=${selectedEventId}`
    - Parse response as `{ link: object | null, payments: array, stats: { totalPayments, matchedPayments, unmatchedPayments, totalAmountMinor } }`

    **UI structure (shadcn Card-based, collapsible):**
    1. **Header row:** Event picker (`<select>` over events prop), collapse toggle, "Create Tikkie link" button
    2. **Summary bar (when link exists):** Total payments count, matched count (green), unmatched count (yellow/orange), total amount (formatMoney)
    3. **Payment list (when expanded + link exists):** Table with columns: Payer Name, Amount, Date, Status (matched/unmatched badge), Action (Assign button on unmatched rows)
    4. **Assign button handler:** Opens a modal/dropdown similar to `AssignDialog` pattern — list orders to match against, PATCH to `/api/dashboard/tikkie-event-links` with `{ paymentId, orderId }`
    5.     **Auto-match button:** Calls PATCH or POST to `/api/dashboard/tikkie-event-links` to trigger auto-match, then refetches. Use fetch() to the REST API (not Convex hooks) since generated types may not include Phase 14 functions yet.
    6. **Empty state:** When no link exists, show "No Tikkie link for this event" + create button
    7. **Loading state:** Skeleton cards matching the layout

    **Create link handler:**
    - POST to `/api/dashboard/tikkie-event-links` with `{ eventId: selectedEventId, providerEventId: selectedEventId }`
    - On success, refetch event data

    **formatMoney helper:** Reuse same pattern as financial page — `Intl.NumberFormat("en-US", { style: "currency", currency: "EUR" }).format(minor / 100)`

    **Match status badge:**
    - `matched` / `auto_matched` / `manual_assignment` → green Badge
    - `unmatched` → yellow/orange Badge
