# Plan 15-02: Attendee detail + reconciliation Tikkie cleanup

## Objective

Remove per-attendee and per-order Tikkie link creation and status display from the attendee detail and reconciliation pages. Replace per-attendee Tikkie section on attendee detail with event-level matched payments. Remove per-attendee amount override UI.

**Purpose:** Centralize Tikkie management on the financial page (15-01). Attendee detail and reconciliation should no longer handle Tikkie link creation — they only display matched payment info from the event-level link.

**Output:** Cleaned-up attendee detail and reconciliation pages with Tikkie UI removed.
