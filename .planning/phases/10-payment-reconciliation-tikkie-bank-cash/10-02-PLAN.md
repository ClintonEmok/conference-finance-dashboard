  <files>app/api/payments/bank-transfer/route.ts</files>
  <action>
Create POST /api/payments/bank-transfer endpoint:

1. Validate auth (require session)
2. Accept body:
   ```typescript
   {
     orderId: string,        // Required - select order first
     amountMinor: number,     // Required
     paidAt: string,         // ISO date string
     payerName: string,      // Required
     payerAccountNumber?: string,
     reference?: string,     // Bank reference
     notes?: string
   }
   ```
3. Validate: orderId exists, amountMinor > 0
4. Create Payment record:
   - source: 'bank_transfer'
   - status: 'manual_assignment' (since admin selected order directly)
   - matchedBy: user ID from session
   - matchedAt: now()
5. Return created Payment with 201 status

Follow API patterns from existing routes (e.g., app/api/dashboard/tikkie-links/).
</action>
