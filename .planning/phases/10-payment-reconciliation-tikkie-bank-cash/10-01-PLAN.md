  <action>
Add the following models to prisma/schema.prisma after TikkiePaymentLinkTransition:

```prisma
enum PaymentSource {
  tikkie
  bank_transfer
  cash
}

enum PaymentMatchStatus {
  auto_matched
  manual_assignment
  ambiguous
  unassigned
}

model Payment {
  id                    String             @id @default(cuid())
  source                PaymentSource
  sourceId              String?            // Tikkie: payment ID, Bank/Cash: internal

  // Payer info (from payment)
  payerName             String
  payerAccountNumber    String?

  // Amount
  amountMinor          Int
  paidAt               DateTime

  // Linkage
  orderId              String?
  status               PaymentMatchStatus @default(unassigned)
  matchedAt            DateTime?
  matchedBy            String?            // 'auto' or user ID

  // Manual entry specifics
  reference            String?            // Bank transfer reference
  notes                String?

  // Source data preservation
  providerPayload       Json?

  createdAt            DateTime           @default(now())
  updatedAt            DateTime           @updatedAt

  @@index([orderId])
  @@index([source, sourceId])
  @@index([status])
}
```

Run `npx prisma db push` to update the database.
</action>

<task type="auto">
  <name>Create payment domain functions</name>
  <files>lib/domain/finance/payments.ts</files>
  <action>
Create lib/domain/finance/payments.ts with:

1. **syncTikkiePayments(paymentRequestToken: string)** - Fetches payments from Tikkie API, stores new ones:
   - Call getPaymentRequestPayments(paymentRequestToken)
   - Check for existing payments by sourceId
   - Create new Payment records for unseen payments
   - Return count of new payments synced

2. **autoMatchPayments()** - Runs auto-matching for unassigned payments:
   - Find all payments where status = 'unassigned'
   - For each, find orders where LOWER(buyerName) = LOWER(payerName)
   - If exactly 1 match: update payment.orderId, status = 'auto_matched', matchedAt = now(), matchedBy = 'auto'
   - If >1 match: set status = 'ambiguous' (manual review)
   - Return matching results

3. **getPaymentById(id: string)** - Get single payment with order
4. **getPayments(filters)** - List payments with optional filters (status, source, orderId)

Follow patterns from lib/domain/finance/tikkie-links.ts for structure.
</action>
