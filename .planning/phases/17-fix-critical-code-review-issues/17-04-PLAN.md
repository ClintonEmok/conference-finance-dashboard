<objective>
Make the dashboard resilient to render failures and route transitions while removing duplicated money-formatting logic.

Purpose: Today a render crash can blank the whole operator UI, and route transitions have no App Router loading surface. This plan makes failure and loading states explicit without redesigning the dashboard.
Output: Root/dashboard error boundaries, route loading files for major dashboard areas, a shared dashboard error component, and a shared `formatMoney` utility adopted across the duplicated call sites.
</objective>
