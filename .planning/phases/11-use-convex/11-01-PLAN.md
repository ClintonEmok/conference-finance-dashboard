<task type="auto">
  <name>Update API routes to use Convex</name>
  <files>app/api/**/*.ts</files>
  <action>
    Update all API routes to call Convex functions instead of using Prisma directly:
    
    For each route file:
    1. Remove direct prisma imports
    2. Import and call appropriate convex functions
    3. Keep auth checks (auth.api.getSession) - these will use Convex Auth
    
    Example transformation:
    ```typescript
    // Before (Prisma)
    const orders = await prisma.ticketTailorOrder.findMany(...)
    
    // After (Convex)
    const convex = getConvexClient()
    const orders = await convex.query(functions.orders.getOrders, {...})
    ```
    
    Or use server-side calls via HTTP to Convex:
    ```typescript
    const response = await fetch(process.env.NEXT_PUBLIC_CONVEX_URL + "/api/orders/getOrders", {
      headers: { ... }
    })
    ```
    
    Alternatively, convert routes to directly call convex functions via ctx:
    - Update route handlers to import and call Convex functions
    - This is the recommended approach for Next.js App Router
  </action>
  <verify>API routes return data from Convex functions</verify>
  <done>All API routes work with Convex backend</done>
</task>
