# Phase 21 Plan 02: Redesign Event Settings Accommodation Section

**Goal:** Make event settings page the primary inline interface for accommodation setup - enable, link hotels, create hotels, create room types, provision rooms all in one place.

## Prerequisites

- Read `21-CONTEXT.md` § "User Flow Model", "Inline UI Behavior", "Guardrails and Status"
- Read `app/dashboard/events/[slug]/page.tsx` lines 845-968 (current accommodation section)
- Read `app/dashboard/accommodation/inventory/page.tsx` lines 528-673 (3-step provisioning modal for reference)

## Tasks

### 1. Analyze Current UI

**1.1** Read event settings accommodation section:

- Toggle for accommodationEnabled (lines 845-886)
- Linked Hotels section with dropdown (lines 889-968)
- Note current component structure and state management

**1.2** Identify reusable components:

- Hotel list/card components
- Room type display components
- Form dialogs used in inventory page

### 2. Design New Accommodation Section

**2.1** Section structure:

```
┌─ Accommodation --------------------------------────────┐
│ [Toggle] Enable accommodation for this event           │
│                                                        │
│ When enabled:                                          │
│ ┌─ Linked Hotels --------------------------------┐     │
│ │ Grand Hotel Amsterdam          [12 rooms] [✕] │     │
│ │ └─ Double: 6 rooms | Quad: 6 rooms            │     │
│ │                                               │     │
│ │ Hilton Rotterdam               [8 rooms]  [✕] │     │
│ │ └─ Double: 4 rooms | Quad: 4 rooms            │     │
│ │                                               │     │
│ │ [+ Add Hotel]                                 │     │
│ └───────────────────────────────────────────────┘     │
└────────────────────────────────────────────────────────┘
```

**2.2** Design states:

- Toggle off: Section collapsed, hint text
- Toggle on: Full section visible
- Empty state: "No hotels linked. Add a hotel to start."
- Loading state: Skeleton cards
- Error state: Inline error messages

### 3. Build Linked Hotel Cards

**3.1** Create `LinkedHotelCard` component:

- Props: hotel data, room counts, room types, onUnlink
- Show: hotel name, city, total rooms, bed capacity
- Expandable: show room breakdown by type
- Actions: Unlink button (with confirmation), Add Rooms button

**3.2** Add status indicators:

- "Ready" (green) - hotel has rooms
- "Needs rooms" (yellow) - hotel linked but 0 rooms
- Tooltip/warning explaining status

### 4. Build "Add Hotel" Flow

**4.1** Create `AddHotelDropdown` component:

- Searchable dropdown of all global hotels
- Show: hotel name, city, room count (or "0 rooms")
- Highlight hotels already linked (disabled)
- Bottom option: "+ Create new hotel"

**4.2** Handle "Create new hotel":

- Opens compact inline form (not full modal)
- Fields: name (required), city (optional)
- On save: creates hotel, auto-links to event, shows in list
- Immediately prompts to add rooms

### 5. Build Inline Room Management

**5.1** Add "Add Rooms" button to hotel cards:

- Opens compact inline form
- Select room type from global types
- Specify quantity
- On save: creates rooms + auto-generates slots

**5.2** Add "Create Room Type" option:

- Compact inline form
- Fields: label, default capacity
- On save: creates type, available immediately in Add Rooms dropdown

### 6. Add Guardrails and Validation

**6.1** Warning when linking hotel with 0 rooms:

- Show yellow warning banner on hotel card
- Text: "This hotel has no rooms yet. Add rooms before attendees can be assigned."
- Don't block, just warn

**6.2** Confirm unlink:

- If hotel has room assignments, show warning
- Text: "This hotel has X attendees assigned. Unlinking will unassign them. Continue?"

**6.3** Disable unlink if hotel is in use:

- Check if any rooms have assignments
- Disable button with tooltip: "Cannot unlink - attendees are assigned"

### 7. Integrate with Existing State

**7.1** Use existing hooks:

- `useEventHotels(eventId)` - get linked hotels
- `useLinkHotelToEvent()` - link hotels (unified mutation)
- `useHotels()` - get all hotels for dropdown

**7.2** Add new hooks if needed:

- `useCreateHotelAndLink()` - create + link in one call
- `useUnlinkHotelFromEvent()` - unlink with validation

### 8. Update Event Settings Page

**8.1** Replace existing accommodation section (lines 845-968):

- Keep toggle
- Replace Linked Hotels section with new inline design
- Add state management for expanded/collapsed hotels

**8.2** Add loading states:

- Skeleton for hotel cards while loading
- Optimistic updates for add/remove operations

**8.3** Handle errors:

- Inline error messages on failed operations
- Toast notifications for success
