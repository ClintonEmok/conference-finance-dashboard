# Phase 21 Plan 01: Consolidate Hotel Linking + Auto-Slot Generation

**Goal:** Merge the two parallel hotel-linking mutations into one unified mutation, add automatic slot generation when rooms are provisioned/linked.

## Prerequisites

- Read `21-CONTEXT.md` § "Hotel Linking Architecture" and "Slot Generation"
- Read `convex/accommodation.ts` lines 1434-1550 (existing mutations)

## Tasks

### 1. Analyze Current Mutations (Research)

**1.1** Read `linkHotelToEvent` mutation (lines ~1434)

- Document current arguments: eventId, hotelId
- Document validation logic
- Document error handling

**1.2** Read `attachHotelToEventByProviderId` mutation (lines ~1487)

- Document current arguments: hotelId, eventProviderEventId
- Document validation logic

**1.3** Read `generateSlotsForRoom` (lines ~1538)

- Understand slot generation logic

### 2. Design Unified Mutation

**2.1** Define unified `linkHotelToEvent` mutation signature:

```typescript
args: {
  eventId: v.string(),
  hotelId: v.string(),
  autoGenerateSlots?: v.optional(v.boolean()), // default true
}
```

**2.2** Consolidate validation logic from both mutations:

- Verify event exists
- Verify hotel exists
- Verify event has accommodationEnabled = true
- Check for existing link (prevent duplicates)

**2.3** Add auto-slot generation:

- After linking, query all rooms for the hotel
- For each room, call slot generation logic
- Run in same transaction for consistency

### 3. Implement Unified Mutation

**3.1** Update `convex/accommodation.ts`:

- Rewrite `linkHotelToEvent` with consolidated logic
- Add auto-slot generation step
- Add proper error messages
- Add returns validator

**3.2** Update type exports in `convex/_generated/api.d.ts` (regenerate)

### 4. Add Auto-Slot to Room Creation

**4.1** Update `createRooms` mutation:

- After creating rooms, check if hotel is linked to any events
- For each linked event, generate slots for new rooms
- Make optional with `autoGenerateSlots` parameter

**4.2** Update `createHotel` mutation (optional):

- If hotel created and immediately linked in same call, generate slots

### 5. Deprecate Old Mutation

**5.1** Mark `attachHotelToEventByProviderId` as deprecated:

- Add JSDoc @deprecated comment
- Add console.warn when called (if kept for backward compat)

**5.2** Update `lib/convex/hooks/accommodation.ts`:

- Deprecate `useAttachHotelToEventByProviderId` hook
