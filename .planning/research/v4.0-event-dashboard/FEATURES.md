# v4.0 Research: Features

## Table Stakes

- Stats-led event Overview with attendance, ticket/order, financial, and accommodation context.
- Concise event navigation for Overview, Attendees, Tickets, Finance, Accommodation, and Settings.
- Finance workspace grouping Orders, Payments, Donations, and Reconciliation.
- Accommodation workspace grouping Hotels and Allocation.
- Intentional loading, error, empty, and no-access states.
- Usable desktop and mobile layouts.

## Differentiators

- Overview prioritizes actionable exceptions rather than only totals.
- Useful tab counts without noisy primary navigation.
- Settings owns sharing and event configuration.

## Anti-Features

- No new cross-event analytics product.
- No duplicated finance or accommodation queries solely for presentation.
- No Ticket Tailor or public signup redesign in this milestone.
